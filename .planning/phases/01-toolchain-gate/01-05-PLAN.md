<objective>
Close TOOL-04: prove the packaged artifacts still build on Windows, macOS and Linux, and that the operator's path through the app still works on a packaged build with all three named native modules callable.

Purpose: this is the only phase criterion that cannot be satisfied on one machine. `build.yml` currently runs `npm ci` and `npm run build` and stops there — it never packages, so nothing in CI has ever produced an artifact with `electron-builder`, and nothing in CI has ever run the smoke flow on Windows or Linux. `ci.yml` and `playwright.yml` are both `workflow_dispatch`-only, so no badge means anything until a run is dispatched and its URL recorded. `playwright.yml`'s virtual screen is `1280x960`, which would clamp a 1920x1080 output window on Linux and quietly make the pixel gate meaningless there. And only `-darwin` pixel baselines are committed, so the default `updateSnapshots: "missing"` mode would make every fresh Linux dispatch fail its pixel assertions on the first attempt and then pass on retry against baselines written moments earlier — a self-referential result that must not be what the checkpoint approves.

Output: a `build.yml` that packs on all three platforms and then runs the smoke spec against each unpacked artifact, a smoke spec that asserts the operator flow and exercises three native addons for real, an executed `RELEASE-SMOKE.md` with run URLs, a documented `workflow_dispatch` capture path for per-OS pixel baselines, and an honest statement of which claims rest on CI artifacts alone.
</objective>
